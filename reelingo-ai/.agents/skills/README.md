# Agent skills

Project-owned skills route coding agents to `reelingo-ai` source-of-truth rules and
documents without copying their details.

| Skill                                                 | Use it for                                                                                               |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| [ai-agent-development](ai-agent-development/SKILL.md) | Agents, workflows, providers, tools, memory, RAG, media, internal contracts, and AI-service verification |

Add another skill only for a distinct reusable workflow. Project decisions belong
in `rule.md` or `docs/`; skills should link to them instead of becoming a second
source of truth.
